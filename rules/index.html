Правила для отрисовки схем

В слоях в иллюстраторе:
Если название сектора начинается с цифры, вначале надо поставить букву «s». Название сектора обязательно должно начинаться с буквы.
В название сектора могут быть только латинские буквы, цифры, дефис «-», нижнее подчеркивание «_». Нельзя использовать другие символы и пробелы.
Названия не должны повторяться. Если в схеме такие сектора есть, дублёрам надо присваивать логические атрибуты: left, right, top, up, bottom, down, 2, 3 и тд.
На схеме в иллюстраторе:
Нельзя использовать переносы строк. Если в названии несколько строчек, каждую строчку надо делать отдельным слоем внутри сектора.
Для всего текста на схеме необходимо выставлять трекинг «0».
Необходимо все эллипсы преобразовывать в контуры
Для секторатора:
При сохранении сектора, его название должно совпадать с названием сектора в слоях в иллюстраторе
